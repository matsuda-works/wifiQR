# WiFi QRコード生成ツール (WiFi Connect QR)

自宅やオフィスのWiFiに簡単に接続するためのQRコードを生成するWebツールです。  
カメラでスキャンするだけで、SSIDやパスワードを手動入力することなくワンタップでWi-Fiに接続できます。

---

## 🌟 主な特徴

- **簡単＆高速生成**: SSID、パスワード、セキュリティ形式を入力してボタンを押すだけで即座にQRコードを生成。
- **プライバシー重視（クライアントサイド完結）**: 入力されたWiFi情報やパスワードはサーバーに一切送信されず、すべてブラウザ内（ローカル）で処理されます。
- **モダン＆洗練されたUI**: グラスモーフィズム調の美しいカードデザインとスムーズなアニメーション。
- **画像ダウンロード機能**: 生成したQRコードをワンクリックでPNG画像として保存可能（印刷や配布に便利）。
- **特殊文字対応**: SSIDやパスワードに含まれるエスケープが必要な文字（`;`, `:`, `,`, `\`）も適切に自動処理。

---

## 🚀 使い方

1. リポジトリをクローンまたはダウンロードします。
2. `index.html` をお使いのブラウザ（Google Chrome, Edge, Safari, Firefoxなど）で開きます。
3. 以下の情報を入力・選択します：
   - **ネットワーク名 (SSID)**: お使いのWi-Fiネットワーク名
   - **パスワード**: Wi-Fi接続パスワード
   - **セキュリティ**: 暗号化方式（WPA/WPA2/WPA3、WEP、または なし）
   - **非公開ネットワーク**: ステルスSSIDの場合はチェックを入れます
4. **「QRコードを生成」** をクリックします。
5. スマートフォンの標準カメラ等でスキャンして接続できるかテストします。
6. 必要に応じて **「画像を保存」** をクリックし、PNGファイルをダウンロードします。

## 🔒 セキュリティとプライバシー

本ツールは完全な静的Webアプリケーションです。外部サーバーとの通信はフォントとCDNスクリプトの取得のみであり、**ユーザーがフォームに入力したWi-Fi資格情報は外部へ一切送信されません**。安心してお使いいただけます。
